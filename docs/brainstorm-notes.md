# 壁打ちメモ(Phase 1 成果物)

## スコープ

フル機能。レジュメ・ブログ・コーディング記録・自作CMSをすべてそろえてから、一度に公開する。
推奨案の2段階リリース（第1弾: レジュメ＋ブログ＋CMS、第2弾: コーディング記録）ではなく、ユーザーの判断で一括公開を選んだ。

## ロール定義

| ロール | 説明 | 権限 |
|--------|------|------|
| 訪問者 | 採用担当・リクルーター、フリーランスの依頼主、エンジニア仲間など、サイトを見に来る人 | 公開側の全画面を閲覧できる（ログイン不要） |
| 管理者 | サイトの持ち主（自分）1人 | CMSにログインし、すべてのコンテンツを作成・編集・公開・削除できる |

## コアフロー

「何者かつかみ、作品で確かめる」（訪問者）

`トップで経歴の要点をつかむ → 作品・プロジェクト一覧 → 作品・プロジェクト詳細（背景・工夫・使用技術・画像）→ リンクやGitHubで実物を確かめる`

詳細ページを挟むのは、「作品で信頼できる」体験には背景や工夫まで読める場所が要るため。

## 画面遷移の全体像

### 公開側（ログイン不要）

- 全画面共通のヘッダー: トップ／レジュメ／作品／ブログ／コーディング記録、それと日英の切り替え
- トップ →「経歴をもっと見る」→ レジュメ
- トップ → 注目の作品 → 作品・プロジェクト詳細（「すべて見る」なら作品・プロジェクト一覧へ）
- トップ → 新着 → ブログ記事／コーディング記録詳細
- 作品・プロジェクト一覧 → 作品・プロジェクト詳細 → リンク・GitHub（別タブで開く）
- 作品・プロジェクト詳細からは、一覧に戻れ、前後の作品にも移れる
- ブログ一覧 → ブログ記事、コーディング記録一覧 → コーディング記録詳細
- 日英を切り替えても、今いる画面のまま言語だけが変わる

### 管理側（ログイン必要）

- 管理画面のURLを開く → ログインしていなければログイン画面へ → ダッシュボード
- ダッシュボード → 各管理画面（サイドメニューで行き来できる）
- 各管理画面: 一覧 → 編集 → 保存（ブログとコーディング記録は、プレビュー → 公開）→ 一覧へ戻る
- ログアウト → ログイン画面

### 分岐条件

- 公開側はログイン不要。管理側はログイン画面を除いてすべてログインが必要。
- 公開サイトには、管理画面への入口を置かない（管理画面はURLを直接開いて入る）。

```mermaid

  subgraph 公開側
    Top[トップ] --> Resume[レジュメ]
    Top --> WorkList[作品・プロジェクト一覧]
    Top --> WorkDetail[作品・プロジェクト詳細]
    Top --> BlogPost[ブログ記事]
    Top --> CodingDetail[コーディング記録詳細]
    WorkList --> WorkDetail
    WorkDetail --> External[リンク・GitHub（別タブ）]
    BlogList[ブログ一覧] --> BlogPost
    CodingList[コーディング記録一覧] --> CodingDetail
  end
  subgraph 管理側
    Login[ログイン] --> Dashboard[ダッシュボード]
    Dashboard --> ProfileEdit[プロフィール編集]
    Dashboard --> CareerAdmin[経歴管理]

    Dashboard --> StackAdmin[使用技術管理]
    Dashboard --> BlogAdmin[ブログ管理]
    Dashboard --> CodingAdmin[コーディング記録管理]
  end
```

公開側の各画面は、ヘッダーから相互に行き来できる（図では省略）。

## データ構造(概要)

| エンティティ | 中身 | 関係 |
|---|---|---|
| プロフィール | 名前、写真、自己紹介、SNSリンク | サイト全体で1件（自分） |
| 経歴 | 種類（職歴／学歴）、所属、期間、内容 | — |
| 作品 | 種類（作品／プロジェクト）、概要、詳細本文、画像、期間、リンク、GitHub | 使用技術と多対多 |
| 使用技術 | 名前、アイコン、リンク | 作品と多対多 |
| ブログ記事 | タイトル、本文、公開状態（下書き／公開）、公開日 | — |
| コーディング記録 | タイトル、本文、公開状態（下書き／公開）、公開日 | — |
| 管理者 | ログイン用のアカウント | 1人 |

- 文章の項目は、すべて日本語と英語の両方を持つ。
- 今のDBでは「職歴と学歴（Experience／Education）」「作品とプロジェクト（Work／Project）」が別テーブルだが、一覧画面と管理画面が1つずつなのに合わせて、それぞれ種類で分ける1つのエンティティにまとめる。
- 今のサイトのデータは、公開サイト（https://eastasian.vercel.app/）から抽出して、この形に移す。
- カラム定義は Phase 2 で詰める。
