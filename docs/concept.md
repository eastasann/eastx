# コンセプト: eastx

## 一言でいうと

個人のレジュメ／ポートフォリオサイト eastasian（https://eastasian.vercel.app/）を、「自作CMS＋フロント」の構成のまま作り直し、ブログやコーディング記録も載せられる場所にする。

## 誰のために

- 採用担当・リクルーター: 経歴とスキルを短時間でつかみたい人
- フリーランスの依頼主: 仕事を頼む前に実績を確かめたい人
- エンジニア仲間・コミュニティ: ブログやコーディング記録を読みに来る人
- 自分自身: 経歴や学びを記録し、振り返る場所として使う

## どんな課題を解決するか

今のサイトには次の課題がある。

- 技術が古く、保守がつらい: Nxモノレポ、Next.js Pages Router、Redux/Zustand/Mantine 5、別ホストのExpress API など、構成が重くて手を入れにくい
- CMSでの更新が面倒: 自作の管理画面での更新に手間がかかる
- 見せ方・デザインが今の自分に合っていない: 1ページのレジュメ形式とデザインを刷新したい
- 載せたい中身を載せる場所がない: レジュメ以外（ブログ、コーディング記録）を置けない

## どんな体験を提供するか

- 訪問者はトップを見てすぐに、何ができる人で、どんな経歴かがわかる
- 作品・プロジェクトを掘り下げて実力を確かめられ、信頼できる
- ブログやコーディング記録から、考え方や興味といった人となりが伝わる
- すべての中身を日本語と英語の両方で読める
- 本人は自作のCMSから、手間をかけずに中身を更新できる

## なぜ作るのか

- ポートフォリオ: 転職や案件獲得のために、自分を見せる場所を整えたい
- サイト自体を作品にする: 作り方や設計そのものを、技術力を示す実績にしたい
- 自分の記録の場所: 経歴や学びを、自分のために積み上げていきたい

## 思いついているアイデア（箇条書きでOK）

- 今のレジュメの中身（プロフィール、職歴、学歴、プロジェクト、作品、使用技術）は引き継ぐ
- ブログ・記事を新しく載せる
- コーディング記録を新しく載せる（今のサイトで作りかけだった /coding ページの構想）
- 「CMS＋フロント」に分ける構成は残す。CMSは引き続き自作し、管理画面も作品の一部として、更新しやすさを重視して作り直す
- 日英の切り替えは続ける
- 参考（今の構成）: Nxモノレポ。フロントと管理画面は Next.js、API は Express＋Prisma、DB は Supabase の Postgres
