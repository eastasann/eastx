# web-design-guidelines(当社版)

1. 同じフォルダの guidelines.md を読む(外の URL から取り直さない。PROVENANCE.md)
2. 指定されたファイル(無ければ /biz-design が渡すサイトの HTML・CSS・JS)を読む
3. guidelines.md の Rules と Anti-patterns をすべて当てる
4. guidelines.md の Output Format の形で返す(file:line、短く、前置きなし)
5. /biz-design の点検の記録に結果を貼る。直したら同じ点検をもう一度回す

注意: 規則のうち、当社の framework/writing/ の文体(日本語の表記など)や framework/design.md と食い違うものは、当社の規約を優先し、食い違いを記録に書く(例: 見出しの Title Case は英語のページだけ)。
